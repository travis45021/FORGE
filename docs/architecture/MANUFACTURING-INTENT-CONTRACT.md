# Manufacturing Intent Contract

Manufacturing Intent is the user-visible, versioned description of what FORGE
is being asked to manufacture. It records the source digest, declared printer
capabilities, material, process/profile digest, and the user decisions that
confirmed context and reviewed the Mission.

Intent is not a command and does not authorize hardware. Capability mismatch,
ambiguity, or missing evidence must remain visible and block progression until
the user resolves it. The intent is an input to production and twin workers;
their results remain evidence and must still pass live checks and the mandatory
fourth confirmation.
