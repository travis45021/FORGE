# Gate 1 Release-Artifact Gap Status

Status: Open; no public integrated distribution authorized  
Recorded: 2026-07-26

The current repository has the approved AGPL direction, upstream license
evidence, provenance records, archive/dependency inventories, and preliminary
compatibility notes. It does not yet contain the artifacts needed to close the
public-release compliance gate:

- final FORGE root license expression and complete file-level treatment;
- consolidated `NOTICE` and third-party notices;
- corresponding-source/source-offer publication instructions;
- machine-readable SBOM tied to a reproducible build;
- finalized contributor sign-off/DCO, inbound licensing, trademark, and
  release-source rules (drafts are present);
- finalized plain-language privacy and opt-in sharing terms (drafts are
  present); and
- automated release checks plus qualified legal review.

These are release prerequisites, not optional documentation. Until they are
complete and reviewed, the trusted FORGE tree remains contract-only and Orca
source import/public integrated distribution remains blocked.
