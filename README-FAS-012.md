# FORGE FAS-012

FAS-012 implements the approved `You decide. Forge follows.` interaction
contract. See
`docs/architecture/FAS-012-user-interaction-suggestions-and-attention.md`.

Included:

- AI-free, suggestion-free Simple defaults;
- independent interaction and automation profiles;
- interaction-class delivery controls and quiet hours;
- daily and per-Mission attention budgets;
- suggestion deduplication and evidence-sensitive permanent dismissal;
- strict Draft 2020-12 profile and suggestion schemas;
- deterministic behavioral and regression tests.

Canonical FAS-011 AI Council remains future-gated and is not a runtime
dependency.
