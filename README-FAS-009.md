# FORGE FAS-009

FAS-009 adds governed, immutable policy bundles above the FAS-008 authorization
engine. See `docs/architecture/FAS-009-policy-bundle-governance.md`.

Included:

- strict Draft 2020-12 policy-bundle schema;
- signed, content-addressed candidate bundle example;
- deterministic reference registry;
- constitutional, Sentinel, admin, approval, rollout, immutability, and rollback
  enforcement tests.
